# docs/pm

Project management memory: the development plan and order of operations, kanban snapshots,
decisions, and the prompt/reply log.

Numbered files (`001-*.md`, `002-*.md`, ...) are **append-only**: to change a decision, add the next
number that supersedes it. Unnumbered files (the current kanban, the current plan) are living
documents and are kept current in the same pass as the work they describe.
