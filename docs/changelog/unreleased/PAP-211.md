### Added — PAP-211: dependency licence policy and CI licence gate

- Licence tiers are now data: `ops/licenses/policy.yaml` (allow / review / deny, four usage
  contexts — bundled, server, dev, service — with per-context rules) and
  `ops/licenses/waivers.yaml` (dated waivers; Atlas approves `review`, Justin approves `deny`,
  expired fails). Rust mirrors the allow list in `ops/licenses/deny.toml`.
- `node ops/licenses/check.mjs` classifies every installed package from `pnpm licenses list` and
  `pnpm ls`, writes `reports/licenses.json` (+ SARIF, + Markdown summary) and exits 1 on a
  violation; `node ops/licenses/notices.mjs [--check]` generates `THIRD_PARTY_NOTICES.md`.
  Live run: 228 packages, 0 violations, ~4 s. Dependency-free, 64 tests.
- Paths: `ops/licenses/`, `THIRD_PARTY_NOTICES.md`, `docs/platform/license-policy.md`,
  `docs/evidence/PAP-211/`. The `licenses` CI job is PAP-78's to wire (steps in ADR 0027).
