### Added — PAP-555: domain event envelope, topic registry and transactional outbox

- `@paperos/core/events`: Zod `DomainEvent` envelope, `defineTopic()` registry with a boot-time
  PII and 64 KB guard, `publish(tx, event)`, `on()` / `drainInProcess()`, and the
  `collectEvents` / `expectEvent` Vitest helpers.
- New package `@paperos/db` with `outbox_event` (monthly partitions) and `event_subscription`,
  the Drizzle outbox driver and a PGlite test stack.
- 44 topics registered, `docs/platform/events.md` generated with a `--check` drift gate, and
  `examples/events.ts` proving a row and its event commit or roll back together.
- Paths: `packages/core/src/events/`, `packages/db/`, `packages/config-biome/src/events.ts`,
  `scripts/events-catalogue.ts`, `examples/events.ts`, `docs/platform/events.md`.
- ADR: [0013-domain-events-outbox](../../adr/0013-domain-events-outbox.md)
