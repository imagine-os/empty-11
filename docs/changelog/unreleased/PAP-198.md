### Added — PAP-198: export formats and API limits of import sources

- `docs/research/export-formats-and-api-limits.md`: export formats, auth, rate limits, pagination,
  attachment-URL lifetime, PAP-164 field-type mapping with lossy flags, throughput floors and known
  gaps for Airtable, Notion, ClickUp, monday.com, HubSpot and QuickBooks Online. Every claim carries
  a vendor doc URL and `checkedOn: 2026-09-19`; unknowns are marked `unverified`, never guessed.
- `docs/migration/sources/index.json` (schemaVersion 1): the machine-readable catalogue PAP-199 reads
  for `capabilities.rateLimit` defaults and PAP-208 for run estimates. Nine entries, six researched,
  `xero`, `linear` and `google-sheets` recorded as `pending`.
- Findings that change connector design: Airtable attachment URLs expire in 2 h, HubSpot search cannot
  page past 10,000 results, monday's auto-number column is invisible to the API, ClickUp is 100 req/min
  on common plans, QuickBooks CDC has a 30-day look-back.
- No ADR. Work package 2 (test accounts) is not built here; the NJ-13 sign-up list is in the research
  doc and posted on the issue.
