### Template

* **Package boundaries are machine-checked.** `ownership.json` at the repo root is the one source
  of truth for who owns every `apps/*`, `packages/*` and `packages/core/src/<folder>` directory,
  which imports each may make (`allowedDeps`) and who owns every `@paperos/contract-*`.
  `pnpm gen:deps-rules` generates `.dependency-cruiser.cjs` (rules R1-R12) and the Biome
  `noRestrictedImports` mirror; `pnpm gen:dep-map` generates
  `docs/platform/dependency-map.json` + `.md`; `pnpm lint:deps` is the gate and runs inside
  `pnpm check` (turbo root task `//#lint:deps`). A violation names the rule, the import and the
  owner to ask.
* **`packages/pm` scaffolded** — PM entities and their Drizzle schema land there (PAP-100), not in
  `packages/core/src/pm`; `packages/core/src/index.ts` is now a curated barrel that re-exports
  sub-folder indexes only. New: `packages/boundaries` (tooling),
  `packages/core/src/modules/ownership.ts` (schema + validator).
* Docs: `docs/platform/package-boundaries.md`, `docs/template-guide.md` ("Where code goes"),
  ADR [0026](../../adr/0026-package-boundaries.md).
