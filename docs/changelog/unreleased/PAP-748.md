# Synthetic spec corpus generator: 300 valid page specs and 60-page stress apps

**What:** Generator for deterministic, seeded synthetic page specs in three sizes (10, 60, 300 pages) for validator, pipeline, editor and graph benchmarks.

**Paths:** `packages/spec/fixtures/generate.ts`, `packages/spec/fixtures/corpus/{small,medium,large}/`, `docs/spec/fixtures.md`.

**Decision:** ADR 0015 (PAP-114). Deterministic generation keeps the corpus stable across schema changes; regeneration bumps `corpusVersion` in manifest and is reviewed like any spec PR.
