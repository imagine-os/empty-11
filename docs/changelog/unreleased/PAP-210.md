### Added

- **MCP server catalogue** (PAP-210, [ADR 0021](../../adr/0021-mcp-catalog.md)). Eleven servers
  in `.claude/mcp/catalog.json` — Linear, GitHub, Forgejo, Stripe, Notion, Google Drive, Webflow,
  Miro, Gamma, Playwright, Postgres — each with every tool scope-classed, auth as
  `broker:<service>/<credential>` placeholders only, owning character, and a PAP-209 rubric score
  with two MCP domain extras. Two servers are recorded as denied with their evidence.
- **Nine per-character bundles** at `.claude/agents/<character>/mcp.json`; read-only endpoints for
  every character outside a server's `writeCharacters`. Four servers are wired today: Linear,
  GitHub, Playwright, Stripe.
- **Catalogue validator** at `packages/agents/src/mcp/` (Zod 4 schema, rubric arithmetic, 39
  tests) running inside `pnpm check`: destructive tools reach Atlas alone, every character named
  exists, no credential-shaped string anywhere, stored rubric totals recomputed from their scores.
  `pnpm --filter @paperos/agents mcp:check` runs it alone.
- Docs: `docs/platform/mcp-catalog.md` (table, scope classes, Needs Justin), `.claude/mcp/README.md`
  (adding a server), rows in `docs/reference/surfaces.md`.
