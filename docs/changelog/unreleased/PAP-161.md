### Added — PAP-161: view model (`ViewSpec`, `FieldDef`, `DatasetRef`, dataset registry)

- Strict Zod 4 `viewSpecSchema` for the ten view kinds (grid, kanban, calendar, timeline, gantt,
  gallery, list, form, map, chart) with fields, filter, sorts (5), groups (3, `expandMulti`),
  aggregations, kind options, search, visibility, permissions, sharing and `migrateViewSpec`
  (v1 → v3); `FieldDef` with the closed 31-name `FieldType` enum; `DatasetRef` grammar
  `entity:key` | `custom:id`; `registerDataset()` / `getDataset()` on a `DatasetRegistryPort`.
- Generated JSON Schema (`pnpm --filter @paperos/views gen:schemas`, drift-tested), ten golden
  fixtures over two datasets, 60+ tests including `expectTypeOf`; `filter` is `unknown` until
  PAP-279 lands (`TODO(PAP-279)`, `it.todo`).
- Paths: `packages/views/src/model/`, `packages/views/src/registry/`, `packages/views/schema/`,
  `packages/views/fixtures/`, `packages/views/scripts/`, `docs/platform/view-model.md`.
