### Added — PAP-753: shared spike harness kit

- `spikes/_kit/`: standalone harness measuring bundle size (`vite build` + gzip minus a shared
  React baseline), wall time and memory (`performance.now()`/`process.memoryUsage()`, 3 runs,
  `unstable` outside 5%), and browser FPS (headless Chromium `requestAnimationFrame` sampling
  when cached) into one Zod-generated `results.schema.json`; a scorecard emitter fills
  `docs/platform/library-rubric.md` section 9's YAML shape from measured facts.
- `scripts/spike-new.mjs`: scaffolds `spikes/<PAP-n>-<slug>/` from the kit (root dev script, not
  wired into the root `package.json`).
- Paths: `spikes/_kit/`, `scripts/spike-new.mjs`, `spikes/README.md`,
  `docs/platform/spike-harness.md`, `docs/reference/surfaces.md`.
- ADR: none (infra tooling; no ADR number pre-assigned to PAP-753).
