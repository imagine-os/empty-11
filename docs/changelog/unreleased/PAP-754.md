### Added — PAP-754: reusable compose-smoke workflow

- Reusable GitHub Actions workflow discovering compose stacks under `ops/compose/**` and
  `spikes/oss-products/*`, running each with `docker compose up --wait`, a health probe, and
  `docker stats` capture, with a 20-minute per-job cap and a buildx/GHA image cache.
- Paths: `.github/workflows/compose-smoke.yml`, `ops/ci/compose-smoke/` (discover, probe,
  stats-parsing and result-building scripts, `__tests__/`), `ops/compose/example-postgres/`
  (worked example), `docs/evidence/PAP-754/`.
- ADR: [0025-compose-smoke-workflow](../../adr/0025-compose-smoke-workflow.md)
