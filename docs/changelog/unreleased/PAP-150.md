### Added — PAP-150: unified input event abstraction

- One `InputEvent` union (`press|move|release|cancel|wheel|key|gamepad|voice`) for mouse, touch,
  pen, keyboard, trackpad, gamepad, TV remote and voice, with Zod 4 schemas, generated JSON Schema
  and golden fixtures; components switch on `kind`, never on device.
- Modality detection with a sticky `preferredModality` signal and `data-input-*` on `<html>`;
  spatial focus navigation (`nearestInDirection`) for the d-pad; portable chords (`mod+shift+k`);
  the `Action` declaration that the command registry, voice and the WebMCP surface all read.
- Paths: `packages/input/`, `docs/platform/input-events.md`, `docs/reference/surfaces.md`.
- ADR: [0019-input-events](../../adr/0019-input-events.md)
