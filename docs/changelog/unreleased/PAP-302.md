### Added — PAP-302: shared value types and wire encodings

- `@paperos/core/types`: `Uuid` + `uuidv7()`, `IsoDateTime`/`IsoDate`/`Duration`, `Money`
  (bigint minor units, decimal string on the wire, half-even rounding, largest-remainder
  `allocate`, `CurrencyMismatch`), `ActorRef`, `EntityRef` + the `entity:<type>:<id>` grammar,
  signed keyset cursors (HMAC-SHA-256, `CURSOR_SECRET`) and the `ApiErrorBody` closed union,
  each with a Zod 4 wire schema that renders as JSON Schema.
- `@paperos/db` (new, minimal): `money()`, `actorRef()`, `actorRefCheck()` and `entityRef()`
  Drizzle column helpers. PAP-32 grows the package.
- Paths: `packages/core/src/types/`, `packages/core/examples/types.ts`, `packages/db/`,
  `docs/platform/types.md`.
- ADR: [0011-shared-value-types](../../adr/0011-shared-value-types.md)
