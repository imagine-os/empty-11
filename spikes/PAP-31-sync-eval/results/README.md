# results

`summary.json` and `table.md` are generated by `node scripts/render.mjs` — do not edit them by hand.

`summary.json` follows the PAP-31 interface contract
(`{ engine, initialSyncMs, incrementalP50Ms, incrementalP95Ms, replay200Ms, heapMb, coldStartMs, score }`)
with four added fields so the nulls cannot be mistaken for zeros: `label`, `versions`, `licence`,
`measured` / `measurementScope` / `notMeasuredReason`, and `hardFails`.

`pglite-local.raw.json` is the untouched output of `npm run bench:electric` (3 runs plus medians).

Run-to-run variance on a shared build container is real: across three independent batches the
`initialSyncMs` median moved between 44 and 65 ms and `coldStartMs` between 164 and 195 ms, while
`incrementalP50Ms` held at 2.77-2.79 ms and the replay checksum was byte-identical every time.
Read these numbers as an order of magnitude ("tens of milliseconds"), not as a regression baseline,
until PAP-270 re-runs them on fixed hardware.

## What ran here

| Measure | Status | Notes |
| --- | --- | --- |
| PGlite local store: initial 2k-row shape load, 500 incremental messages, 200-write outbox replay, cold reopen, heap | **measured** | Node 22.22.2 on the build container, 2 x 3 runs, medians in `measurements.json`. Checksum of the replayed rows identical across all runs. |
| Electric server end-to-end (HTTP shape, live tail, p50/p95 over the wire) | not measured | Needs `docker run electricsql/electric:1.8.1` against a Postgres with `wal_level=logical`. No Docker daemon on this container. |
| `zero-cache` | not measured | Needs Docker + Postgres replica. |
| `powersync-service` + `@powersync/web` | not measured | Needs Docker + Postgres, and wa-sqlite needs a browser with OPFS. |
| Browser heap and timing at 375 and 1280 (Playwright) | not measured | No browser binaries on this container. |
| Android emulator cold start (`adb`) | not measured | No emulator or Android SDK. |
| Cross-tenant shape request must fail, per engine | not measured end-to-end | Reasoned from the auth docs instead; the executable version is PAP-270's proxy test (`SHAPE_FORBIDDEN`, 403). |
